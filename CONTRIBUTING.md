# Contributing

Thanks for considering a contribution.

## How

- **Issues**: open one for bugs, feature ideas, or design questions. For anything non-trivial, please discuss before sending code so we don't end up with conflicting work.
- **Pull requests**: small fixes welcome without prior discussion. Format with `cargo fmt`, lint with `cargo clippy --release`, add tests under `tests/` where it makes sense.
- **Build**: `cargo build`. Tests: `cargo test`.
